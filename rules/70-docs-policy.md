## Documentation Policy

- **Do NOT create status/summary markdown files** (`STATUS.md`, `FIXES_APPLIED.md`, `CHANGES_SUMMARY.md`, `*_SUMMARY.md`, walkthroughs) unless the user explicitly asks. This repo had doc-sprawl incidents — don't repeat them.
- Permanent docs are `README.md` and `AGENTS.md` only. Design notes go under `docs/` and only when requested.
- Never create a document just to describe the change you just made — the commit message and code are the record.
- AGENTS.md holds durable invariants and footguns, not in-progress feature specs. Specs belong in issues/branches, not here.
- Keep this file's Overview/Layout section accurate when the project structure changes.
