# Changelog

## 1.2.0 — 2026-10-14

- New fragment `91-docker.md` + `docker` stack token: detects `Dockerfile*`,
  `docker-compose*.yml`, `compose.{yml,yaml}` at root or one level deep.
  Covers real footguns found in existing projects: `.env` baked into images,
  hardcoded compose passwords, missing `.dockerignore`, unpinned/non-LTS base
  images (rule: `lts-alpine` or explicit LTS major, never `:latest`), `|| true`
  in CMD swallowing migration failures, empty committed Dockerfiles.

## 1.1.0 — 2026-10-14

- sync.sh now writes `.github/copilot-instructions.md` (pointer stub) at the
  project root for every synced project.
- `rules/_template.md`: skeleton + documented process for adding new fragments
  when new footguns emerge.
- Fix: hand-written `CLAUDE.md` files are now backed up to `.bak` before being
  replaced (previously deleted without backup).
- Stubs now carry the `GENERATED by ai-rules` banner for consistent
  foreign-file detection.

## 1.0.0 — 2026-10-14

- Initial release. Rule fragments for: JS code style, Fastify backend, Prisma,
  Supabase, React/Vite/Tailwind/Zustand frontend, testing (Vitest + node:test for
  new code), git hygiene, docs policy (anti doc-sprawl), security/env, Vercel
  deploy. Python stub. `sync.sh` with stack detection, `--check`, `--all`,
  `--stack` override, CLAUDE.md symlink-or-stub.
