# Changelog

## 1.4.0 — 2026-10-14

- `60-git-hygiene.md` expanded with two new sections:
  - **Branches**: trunk-based workflow off `main`, `<type>/<scope>-<short-desc>`
    naming (`feat|fix|chore|refactor|docs|test|hotfix`), one concern per branch,
    always pull `main` before branching, rebase-before-PR, `main` always
    deployable, `hotfix/*` exception with back-porting requirement.
  - **Atomic Commits**: each commit builds and does one thing, `git add -p` for
    splitting working trees, refactor → feature → docs/tests ordering, squash
    WIP before merge, Conventional Commits only when the repo already uses them,
    no amend/force-push on reviewed PRs.

## 1.3.0 — 2026-10-14

- New fragment `15-repo-structure.md`: canonical domain-driven layout —
  `backend/src/modules/{domain}/{routes,service,repository,schemas}` +
  `shared/` for cross-cutting; one-way `routes → service → repository → ORM`;
  `api/` reserved for Vercel serverless; gradual convergence for existing
  projects. Applied unconditionally to all JS projects.
- `30-backend-fastify.md` rewritten for the modular domain model
  (modules/, shared/plugins/, shared/errors/).
- `35-db-prisma.md` / `36-db-supabase.md`: ORM confined to `*.repository.js`;
  singleton clients moved to `src/shared/clients/`.
- `20-code-style-js.md` / `40-frontend-react.md`: aligned to the real frontend
  convention — `src/services/api.js` (not `lib/`).

## 1.2.0 — 2026-10-14

- New fragment `91-docker.md` + `docker` stack token: detects `Dockerfile*`,
  `docker-compose*.yml`, `compose.{yml,yaml}` at root or one level deep.
  Covers real footguns found in existing projects: `.env` baked into images,
  hardcoded compose passwords, missing `.dockerignore`, unpinned/non-LTS base
  images (rule: `lts-alpine` or explicit LTS major, never `:latest`), `|| true`
  in CMD swallowing migration failures, empty committed Dockerfiles.

## 1.1.0 — 2026-10-14

- sync.sh now writes `.github/copilot-instructions.md` (pointer stub) at the
  project root for every synced project.
- `rules/_template.md`: skeleton + documented process for adding new fragments
  when new footguns emerge.
- Fix: hand-written `CLAUDE.md` files are now backed up to `.bak` before being
  replaced (previously deleted without backup).
- Stubs now carry the `GENERATED by ai-rules` banner for consistent
  foreign-file detection.

## 1.0.0 — 2026-10-14

- Initial release. Rule fragments for: JS code style, Fastify backend, Prisma,
  Supabase, React/Vite/Tailwind/Zustand frontend, testing (Vitest + node:test for
  new code), git hygiene, docs policy (anti doc-sprawl), security/env, Vercel
  deploy. Python stub. `sync.sh` with stack detection, `--check`, `--all`,
  `--stack` override, CLAUDE.md symlink-or-stub.
